# Aplicación web — alcance futuro

No existe un dashboard implementado ni desplegado. Las tablas y figuras de las
preguntas EDA 1–5 se generan en Google Drive y deben validarse antes de diseñar
una interfaz.

Una fase futura deberá definir usuarios, decisiones, métricas y controles de
privacidad antes de elegir Streamlit, Dash u otra tecnología.
