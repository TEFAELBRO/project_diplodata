# Reportes

Git contiene únicamente documentación técnica. Los resultados ejecutados no se
versionan porque dependen de fuentes ubicadas en Google Drive.

Al ejecutar el pipeline, las tablas y figuras se guardan en:

```text
MyDrive/datav3/project_diplodata_outputs/eda_01_05_v1/reportes/
```

No cite un resultado hasta revisar los inventarios y controles en la carpeta
`audit/` de la misma ejecución.
